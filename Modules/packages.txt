What is a Package?
A package is a folder that contains multiple Python modules.
👉 Simple idea:
Module = single file
Package = folder of files (modules)


Example :
module1.py :
def add(a, b):
    return a + b

module2.py :
def sub(a, b):
    return a - b

main.py :
from mypackage import module1
print(module1.add(5, 3))

What is __init__.py?
This file tells Python:
👉 “This folder is a package”
Even if empty, it is important (especially for understanding structure).
