What is a Package?
A package is a folder that contains multiple Python modules.
👉 Simple idea:
Module = single file
Package = folder of files (modules)

Why Packages?
When your project grows:
Too many modules → messy
So we group them into packages

module1.py :

def add(a, b):
    return a + b

def sub(a, b):
    return a - b
