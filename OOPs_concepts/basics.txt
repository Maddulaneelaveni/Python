What is OOPS (Object-Oriented Programming)?
OOPS (Object-Oriented Programming System) is a programming approach where you structure your code using objects and classes instead of just functions and logic.

Example :
A class is a blueprint 🏗️
An object is a real-world instance created from that blueprint 🚗
👉 Example:
Class = Car
Objects = Audi, BMW, Tesla

Core Concepts of OOPS :

1. 🧱 Class
A class is a template that defines properties (variables) and behaviors (methods). or a blueprint of an object.
Example : 
class Car:
    def start(self):
        print("Car started")

2. Object
An object is an instance of a class.
EX:
c1 = Car()
c1.start()

3. Attributes (Variables / Properties) :
Attributes are the data or variables that belong to a class or object.
They describe the state (properties) of an object.
#Ex:
class Student:
    def __init__(self, name, age):
        self.name = name   # attribute
        self.age = age     # attribute
Here:
name and age are attributes
## Types of Attributes :
1.Instance attributes → unique for each object (self.name)
2.Class attributes → shared by all objects

4. Methods (Functions inside class) :
Methods are functions defined inside a class that describe the behavior (actions) of an object.
